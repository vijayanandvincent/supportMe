# CPU High Usage Scenario

## Objective
Simulate high CPU usage on a Linux system and teach support engineers how to monitor and troubleshoot performance issues.

## Instructions
1. Check current CPU usage.
2. Simulate high CPU load.
3. Observe system behavior and analyze logs.

## Gamification Points
- Step 1: 10 points for identifying normal CPU usage.
- Step 2: 20 points for successfully generating CPU load.
- Step 3: 30 points for analyzing CPU behavior.
